# Disk Health (v0.2.0)

Une application macOS native (SwiftUI) permettant d'analyser la santé des disques NVMe internes et externes.

## Nouveautés de la v0.2.0
- Nouvelle interface avec barre latérale (navigation Disques & Volumes) et barre d'outils macOS.
- Historique des températures stocké localement et restitué sous forme de graphique évolutif.
- Outil d'export pour copier un résumé ou extraire le rapport S.M.A.R.T complet en JSON.
- Inspecteur de détails avancé (raccourci ⌘I).
